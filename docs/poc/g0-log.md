### 발견

1. **C안(순수 Dart TTF)은 PoC 범위에서 충분하다.** 첫 실행에 OTS·fontTools를 통과했고 Rust 의존성이 없다. `fontations`(A안)는 Android 빌드에 `cargo-ndk`가 필요하다.
2. **동적 폰트 등록 방식으로 메모가 즉시 손글씨로 표시된다.** IME·커서·선택은 Flutter 기본 동작을 그대로 쓴다. 등록 지연(디버그 75ms)이 새 글자 입력 때마다 생기므로, 실기기 릴리스 빌드에서 측정이 필요하다. → PRD §8에서 기각한 "편집마다 TTF 등록"은 "메모 글자만 담은 작은 폰트 + 고유 패밀리 이름"으로 바꾸면 성립한다. RISK-07 대체안과 주 방식의 순서를 바꾸는 것을 검토한다.
3. **규칙 v0 품질 문제:** 윤곽선을 통째로 축소하므로 받침 있는 음절의 획이 가늘고, 자모 bbox에 맞추므로 크기가 들쭉날쭉하다(`build/poc/sample.png`).
4. **설계 단서 (OQ-01):** 사용자 입력은 획(중심선 + 필압)이므로, 윤곽선이 아니라 **획의 점을 자리로 옮긴 뒤 펜 굵기를 다시 입히면** 받침이 있어도 획 굵기가 일정하다. 기본 글리프를 윤곽선이 아닌 원본 획으로 조합하는 방식을 다음 회차에서 실험한다.

## 2회차 (2026-11-19) — 획 단위 조합 (규칙 v1)

### 만든 것

- `lib/hangul/composer.dart`: `BaseGlyph`(원본 획 + 윤곽선), `CompositionRule` v0/v1. v1은 기본 글리프 **획의 점**을 자리로 옮긴 뒤 같은 펜(56 단위)으로 다시 입힌다. 획이 없는 기본 글리프는 v0으로 넣는다. 얇은 자모(ㅡ, ㅣ)는 얇은 방향으로 늘리지 않는다.
- `lib/dev/stroke_fixture.dart`: 기본 자모 35자(자음 14 + 모음 21)를 중심선 획으로 정의한 픽스처. 겹자음·겹받침 16자는 조합 엔진이 구성 자음으로 만든다.
- `lib/ink/ink.dart`: 획 윤곽 Douglas–Peucker 단순화(허용 오차 2 단위).
- 메모 화면 조정 메뉴: 조합 v0/v1, 기본 글리프 세트(획 픽스처 / 나눔 펜 윤곽선) 전환.

### 측정 (macOS, `flutter test`)

| 항목 | 단순화 전 | 단순화 후 |
| --- | --- | --- |
| 획 픽스처 v0 (윤곽선 축소) 11,223자 조합 + 빌드 | 830ms, 16.35MB | 478ms, 10.07MB |
| 획 픽스처 v1 (획 단위) 11,223자 조합 + 빌드 | 1,606ms, 14.67MB | 1,800ms, 7.97MB |
| 메모 동적 폰트 11자 (디버그 앱) | | 빌드 13ms, 등록 103ms |

### 발견

1. **획 단위 조합(v1)이 획 굵기 문제를 해결한다** (`build/poc/stroke_v1_vs_v0.png`, 위 v1 / 아래 v0). 받침 유무와 관계없이 굵기가 일정하다. v0은 ㅡ·ㅣ가 뭉툭해지고 받침이 가늘어진다. → **PRD 반영 후보:** 기본 글리프는 원본 획으로 조합한다(FR-04, §5 `BaseGlyph`). 획 데이터가 이미 저장 대상(FR-02)이므로 추가 저장 비용은 없다.
2. **겹받침 자리(닭·꿇·뷁)에서 획이 뭉친다.** 좁은 자리에서 펜이 상대적으로 굵다. 자리 크기에 따라 펜을 조금 줄이거나 배치 유형별 보강 기본 글리프가 필요하다(OQ-01).
3. **파일 크기가 크다.** v1 단순화 후 8.0MB(나눔손글씨 펜 원본 약 3MB). 직선 다각형이라 점이 많다. 2차 곡선 맞춤으로 더 줄일 수 있다(OQ-03, NFR-02).
4. **v1 전체 빌드 1.8초(Mac).** 매번 `perfect_freehand`로 11,172자 획을 다시 입히기 때문이다. iPad에서 측정이 필요하다. 내보내기에서만 생기는 비용이며 메모 표시는 글자 단위라 영향이 작다.

## 3회차 (2026-11-19) — 겹받침 뭉침

### 원인

규칙 v1은 펜 지름이 일정하다. 겹받침의 반쪽 자모는 원래 크기의 25% 안팎까지 줄어드는데 펜은 그대로라 획이 겹쳐 까맣게 뭉친다. 겹받침 자리 자체도 낮고 넓어 자모가 납작하다.

### 바꾼 것 (`lib/hangul/composer.dart`)

- **펜 조절:** 자모 축소율 s에 대해 펜 지름을 `s^k`배로 한다(최소 0.5배). k=0이면 v1, k=1이면 v0과 같다. 기본값 k=0.35.
- **겹받침 자리 높이기:** 기본 글리프가 없는 겹받침(구성 자음으로 만드는 경우)이면 받침 자리 윗변을 6% 올리고 초성·중성 자리를 그만큼 위로 압축한다. 사용자가 겹받침을 직접 그린 경우는 한 자모로 보고 적용하지 않는다.
- 비교 실험: `test/hangul/pen_scale_experiment_test.dart` → `build/poc/pen_scale_compare.png`, `build/poc/pen_zoom.png`

### 결과

| 설정 (k, 받침 높이기) | 관찰 |
| --- | --- |
| (0, 0) — 2회차 v1 | ㄺ·ㄼ·ㄾ이 까맣게 뭉침 |
| (0.35, 0) | 받침이 또렷해지지만 납작함 |
| **(0.35, 0.06)** — 채택 | 받침이 또렷하고 위아래 균형이 가장 좋음 |
| (0.35, 0.10) | 받침이 커지고 `꿇` 윗부분이 눌림 |

- 전체 결과: `build/poc/stroke_v1_r3.png`. 11,223자 조합 + 빌드 1,787ms, 7.39MB.
- 펜 조절로 글자 전체가 2회차보다 조금 가늘어졌다. 기본 펜 지름(56)은 실제 손글씨로 다시 맞춘다.
- **PRD 반영 후보 (OQ-01):** 겹받침은 구성 자음 조합으로도 읽을 만한 품질이 나온다. 필수 기본 글리프에서 겹받침 11자와 쌍자음 5자를 빼고 보강 기본 글리프로 둘 수 있다. 이 경우 필수 기본 글리프는 자음 14 + 모음 21 = 35자다(겹모음을 구성 모음으로 만들면 더 줄어든다).
